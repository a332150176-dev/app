# קו לישיבה — ניהול הסעות לחתונות

אפליקציית Android בעברית לניהול הזמנות אוטובוס, תזכורות, חישוב רווחים וגיבוי מקומי.

## תכונות
- ניהול חתן, תאריך, כתובת אולם, שעות, חברת הסעות, נהג, טלפון, מספר בחורים והערות.
- חישוב: סך לישיבה = מחיר החברה + תוספת תיווך; רווח נקי = תוספת תיווך פחות הוצאות נוספות.
- סטטוסים, סימון שהנהג עודכן, חיפוש וסינון.
- התראות מקומיות ב-Android ביום שלפני החתונה, בשעה שנבחרה, בכפוף להרשאות ולהגדרות מערכת.
- גיבוי ושחזור JSON, וייצוא נתונים CSV.
- נתונים נשמרים מקומית במכשיר; הגיבוי לקובץ אינו סנכרון בענן.

## הורדת APK
1. פתחו את לשונית Actions במאגר GitHub.
2. פתחו את הריצה האחרונה של Build Android APK.
3. תחת Artifacts הורידו את kav-leyeshiva-debug-apk.
4. חלצו את ה-ZIP והתקינו את app-debug.apk באנדרואיד. זהו APK לבדיקה/התקנה ידנית, לא חבילה חתומה לחנות.

הריצה מופעלת אוטומטית בכל push ל-main, וניתן להפעיל אותה גם דרך Actions > Build Android APK > Run workflow.

## בנייה מקומית
דרושים Node.js 22+, Android SDK ו-Java 21. הפקודות נמצאות גם בקובץ workflow.
